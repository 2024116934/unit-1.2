# ELEC2645 Unit 1.2: Arrays and Strings

This repository contains six C programming activities in one folder. Work through them in order, following the guidance in each activity's Markdown file and editing the corresponding C source file.

## Activities

1. [Arrays](activity1_arrays.md)
2. [2D Arrays](activity2_2d_arrays.md)
3. [Strings](activity3_strings.md)
4. [More Strings: Palindrome Checker](activity4_more_strings.md)
5. [Enum and Switch](activity5_enum_switch.md)
6. [Debug Practice](activity6_debug_practice.md)

The [ELEC2645 reference guide](https://eee-elec2645.github.io/) contains further explanations and examples. Use its search box if you need help with a topic.

## Testing your work

Run the test for the activity you are completing:

```text
make test1    Activity 1: Arrays
make test2    Activity 2: 2D Arrays
make test3    Activity 3: Strings
make test4    Activity 4: More Strings: Palindrome Checker
make test5    Activity 5: Enum and Switch
make test6    Activity 6: Debug Practice
```

Running `make test` displays the same list. A failed test is normal while you are working. Read the feedback from `d[o_0]b ELEC2645 Bot`, update your program and run the test again.

Run `make clean` to remove compiled `.out` files.

## Optional: Run and Debug
